## Contents

- `question1.py` - loop-based circle renderer
- `question2.py` - class-based refactor of question 1
- `question3.py` - Depth First and Breadth First traversal
- `question4.py` - generate an SQLite database from Appendix A JSON
- `question5.py` - fix Python lambda late binding
- `appendix_a.json` - Appendix A represented as valid JSON
- `RUN_INSTRUCTIONS.md` - full setup and execution instructions
- `SUBMISSION.md` - submission notes and author information

## Requirements

- Python 3.10+
- No third-party packages are required
- SQLite is accessed through Python's built-in `sqlite3` module
