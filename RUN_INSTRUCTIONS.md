# Run Instructions

Prepared by **Leonid Ksenchuk**

## 1. Requirements

The solution uses only the Python standard library.

Required:

- Python 3.10+
- A terminal / command prompt

No `pip install` command is required.

The following standard-library modules are used:

- `json`
- `sqlite3`
- `pathlib`
- `collections`

## 2. Open the Project Folder

macOS / Linux:

```bash
cd brown_bag_films_technical_test
```

Windows:

```powershell
cd brown_bag_films_technical_test
```

## 3. Verify Python

macOS / Linux:

```bash
python3 --version
```

Windows:

```powershell
python --version
```

## 4. Run the Tasks

### Question 1

```bash
python3 question1.py
```

### Question 2

```bash
python3 question2.py
```
